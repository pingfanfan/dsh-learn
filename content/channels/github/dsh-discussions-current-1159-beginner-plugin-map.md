# DeepSeek Harness Discussions 更新到 #1159：新手入口要把插件装好，更要证明它真的加载了

截至 2026-08-14，官方 Discussions 的公开列表已经观察到 #1159。相对此前复核到的 #1068，新增 #1069–#1159 共 91 条讨论：一边是插件、Skill 和周边工具快速出现，另一边是插件加载、插件创建、路径、工作区和 Windows 原生组件方面的求助。

这不是 DSH 版本发布，也不是官方对第三方项目的兼容性背书。对 dsh-learn 的直接启发是：完全新手教程不能只给 `plugin add`，还要让读者依次确认：

1. Node.js、npm、npx 版本正常；
2. 固定版本 DSH Web UI 能启动；
3. 首次页面可以先不填 API Key；
4. 临时 profile 中的插件完成“安装 → `--dump-config` 看到 bundle → 启动日志看到加载 → 移除”。

新增讨论可分为两类：#1071、#1082、#1094、#1096、#1114、#1129、#1150、#1152、#1154 展示了配置整合、多智能体、调试、图像、凭据、Skill、休眠和费用等生态方向；#1106、#1131、#1140、#1151 则提醒新手，安装返回成功不等于 profile 已启用、入口已执行或路径一定兼容。

因此 dsh-learn 继续把无 Key、隔离 `DSH_HOME`、固定版本、截图带路、终端回执定案作为第一层。社区插件先做索引，不直接变成“复制就能用”的教程；本卡没有下载或运行第三方插件，没有启动 DSH，没有调用模型 API，知乎不自动发布。
